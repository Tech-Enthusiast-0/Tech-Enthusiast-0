### 🚀 Featured Engineering & Architectures

#### 1. [StrataSense — IoT Strata Deformation & Mine Early-Warning Architecture](https://github.com/Tech-Enthusiast-0/stratasense)
*Architected for the **Smart India Hackathon (SIH)** problem statement on underground mining safety.*
* **Architecture:** Full-stack distributed telemetry engine combining **FastAPI**, **Paho-MQTT**, and **WebSockets** with a **React 18 / Vite** GIS Command Center.
* **Core Logic:** Implemented an empirical mathematical risk scoring matrix ($(\theta_{\text{tilt}} \times 0.4) + (v_{\text{vib}} \times 6.0)$) that ingests high-frequency ESP32 sensor streams, updates an interactive Leaflet GIS map at 1 Hz, and triggers non-blocking Telegram emergency webhooks within milliseconds of threshold breaches.

#### 2. 3D Hand-Gesture Recognition Engine (Jujutsu Kaisen Simulation)
*In-browser spatial computer vision and particle simulation.*
* Engineered a real-time computer vision interface in the browser using **MediaPipe Hands** to track finger joints with sub-15ms latency.
* Coupled landmark vectors with **Three.js** canvas shaders to render dynamic anime domain-expansion particle simulations in real time without external server dependencies.

#### 3. Automated Exam Response Sheet Parser (CUET Score Calculator)
*Client-side DOM parser and score normalization utility.*
* Built a high-speed JavaScript engine that parses raw HTML/JSON response sheet outputs from official National Testing Agency (NTA) portals.
* Automates answer key matching, negative marking calculations, and normalization curves, eliminating manual verification fatigue for hundreds of students.

#### 4. Discord Community & Quest Bot Automation
*Event-driven bots and webhook infrastructure.*
* Developed self-hosted Node.js / Python Discord bots managing community roles, event triggers, and gamification quest loops with persistent state tracking.

#### 5. Ecosystem & Research
